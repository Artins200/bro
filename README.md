# Rick and Morty: Portal Gun & Flying Saucer — Garry's Mod Addon

Аддон добавляет портальную пушку и собственный летающий транспорт в стиле тарелки Рика. **Единственное оружие-версия SWEP в аддоне — портальная пушка**; другие игровые сущности лежат отдельно во вкладке `Entities`.

## Что добавлено

### Портальная пушка Рика

- Две связанные портальные точки: ЛКМ — портал A, ПКМ — портал B.
- Режим `MAP SKY`: открой карту сверху и выбери точку для пары порталов.
- `E + R` переключает режимы; `R` закрывает открытые порталы.
- Подробная процедурная 3D-модель пушки и анимированные эффекты.

### Летающая тарелка Рика

Тарелка — полноценный управляемый транспорт с собственной физикой полёта, плавным поворотом, ускорением, форсажем, подсветкой двигателей и камерой от третьего лица. Внутри есть кресло пилота и приборная панель; купол полупрозрачный, поэтому сидящего персонажа видно снаружи.

**Управление:**

- `E` рядом с тарелкой — сесть; `E` в кресле — выйти.
- `W / A / S / D` — движение и боковой манёвр.
- `Пробел` — вверх; `Ctrl` — вниз.
- `Shift` — форсаж.

### Другие сущности

- `Omega Device` — стационарная станция во вкладке `Entities`.
- `Полиция Времени (Time Cop)` — NPC.
- `Rick's Green Portal` — сущность портала.

## Где искать в меню `Q`

- **`Weapons → Rick and Morty`:** `Rick's Portal Gun`.
- **`Entities → Rick and Morty`:** летающая тарелка, станция Omega Device, Полиция Времени и зелёный портал.

## Установка

Положите папку аддона в `GarrysMod/garrysmod/addons/rick_portal_gun/`:

```text
rick_portal_gun/
├── addon.json
├── lua/
├── materials/
└── sound/
```
