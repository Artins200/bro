# bro

Два самостоятельных аддона для Garry's Mod, без Workshop-зависимостей и внешних ресурсов:

| Папка | Что это |
| --- | --- |
| `echo_archive/` | «Эхо-архив» — сканер, контейнеры редкости, опыт и уровни, резонансные бури. |
| `night_visitor/` | «Ночной гость» — кооперативная хоррор-встреча с призраком и фонарём. |

Каждую папку можно скопировать целиком в `garrysmod/addons/`. Подробности — в `README.md` внутри каждой папки. Готовые архивы: `echo_archive.zip`, `night_visitor.zip`.

Все визуальные эффекты собраны из стандартных моделей, спрайтов и материалов Garry's Mod (`vgui/white`, `sprites/light_glow02_add`, `sprites/glow04_noz`), поэтому аддоны работают на чистом клиенте без докачки контента.
